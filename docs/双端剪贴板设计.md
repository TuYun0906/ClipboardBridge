# 双端剪贴板最小版设计

## 操作与界面

Windows 使用可缩放的普通窗口，关闭窗口时转入托盘。左键单击托盘图标打开窗口，右键可显示窗口或退出。设置中的开机自启让程序在登录后直接进入托盘。Android 保留可拖动、缩放和收成小球的浮窗。两端沿用浅灰和蓝色配色，同步与窗口显示独立运行。

设置提供自动发送系统剪贴板、显示浮窗、局域网与公网模式。Android 另有自动发送新截图和相机照片的开关。开启后以短促淡入淡出的提示确认，后台识别通过共享媒体库完成，只处理开启后新保存且已写完的图片。手动选图走系统选择器。

## 双端连接

Windows 作为连接端点，Android 主动连接并自动重连。局域网下在 Android 输入 Windows 局域网地址，使用一次性复制的配对串绑定 Windows 证书指纹和随机访问密钥。两端以 TLS 传输，Android 校验证书指纹，Windows 校验访问密钥。每次切换传输模式都重建连接。

文本用 UTF-8，图片用原始常见图片格式传输。消息携带类型、长度和唯一 ID。接收后写入系统剪贴板并确认，本机自动监听识别同步写入的内容并抑制回传。断线重连只补发本机尚未确认的最新内容，防止旧内容排队覆盖新复制的项目。收到图片时，Windows 提供图像剪贴板格式，Android 提供带正确 MIME 类型的内容 URI。粘贴图片需由目标应用支持相应格式。

## Android 剪贴板行为

Android 保留当前输入法。前台服务维持连接，接收 Windows 的内容后直接写入系统剪贴板。开启自动发送并授权 Shizuku 后，剪贴板变化会触发发送，应用退到后台和隐藏浮窗时同样有效。Shizuku 停止时，自动读取回到应用获得焦点时触发。关闭自动发送后，可手动输入文字或选图。截图与相机照片通过共享媒体库单独监听。

- [Android 后台剪贴板限制](https://developer.android.com/about/versions/10/privacy/changes#clipboard-data)
- [Android 图片粘贴与内容 URI](https://developer.android.com/develop/ui/views/touch-and-input/copy-paste)
- [Android 共享媒体库权限](https://developer.android.com/training/data-storage/shared/media)

## 公网模式实施方法

在 Windows 和 Android 安装 Tailscale 并加入同一个私有网络。在公网模式中填写 Windows 的 Tailscale 地址或 MagicDNS 名称，沿用已绑定的证书和访问密钥。Windows 防火墙允许私有网络中的手机访问同步端口。用手机蜂窝网络与电脑异地连接验收，路由器无需配置公网端口转发。Tailscale 会尝试直接连接，必要时使用中继。

- [Windows 安装](https://tailscale.com/docs/install/windows)
- [Android 安装](https://tailscale.com/docs/install/android)
- [直连与中继](https://tailscale.com/docs/reference/device-connectivity)

## 最低验收

1. Windows 测试关闭到托盘、左键恢复、右键退出及开机自启。Android 测试拖动、缩放、收球、恢复和隐藏。
2. 两端都开启自动发送，Android 授权 Shizuku。隐藏两端窗口后，分别从其他应用复制含中文和换行的文字，在对端普通编辑器直接粘贴。
3. 两端各用支持图片复制和粘贴的应用测试同样的流程。验证接收内容不会循环同步。
4. 关闭自动读取后，复制动作不发送。在两端分别手动发送文本和图片，确认对端可直接粘贴。
5. Android 打开自动图片开关时出现短提示。分别执行系统截图和相机拍照，在 Windows 直接粘贴图片。关闭后重复，确认不会发送。
6. 断开网络后恢复，验证自动重连及最新内容补发。测试无效配对和错误证书均无法传输。
7. 按使用说明配置 Tailscale，切换两端的公网模式，再用不同网络复核连接。
